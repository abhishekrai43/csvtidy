$ merge and clean CSV files
from the command line

Combine an entire folder of exports into one tidy file, drop duplicates, fix dates — in one command. 100% offline, powered by DuckDB so it streams files bigger than RAM, and driven by reusable recipes.

pip install csvtidy
csvtidy merge ./exports --output combined.csv

csvtidy --help

  • Offline and private. Your data never leaves your machine. No accounts, no uploads.
  • Handles huge files. DuckDB streams and spills to disk — merge CSVs that would crash a spreadsheet.
  • Recipe-driven. Save the cleanup as YAML, re-run it on next month's data with one command.
  • Non-destructive by default. Values are read as text, never silently retyped; unparseable dates keep their original text.
  • Merges messy schemas. Columns are aligned by name across files — reordered or missing columns don't shift data.

csvtidy merge

Combine multiple CSVs, a folder, or globs into one file. Per-file headers are read as headers (never repeated as data rows), and --source-column tags every row with the file it came from.

merge every CSV in a folder into one file
csvtidy merge ./exports --output combined.csv --source-column file
optionwhat it does
-o, --output PATHWrite to this CSV (streamed to disk). Omit to print to stdout.
--source-column NAMEAdd a column with each row's source file name.
--pattern GLOBGlob used when an input is a folder (default *.csv).
-r, --recursiveRecurse into sub-folders.

Doing this by hand in CMD or PowerShell? See the honest comparison: merging CSV files from the command line — copy, PowerShell, and csvtidy.

csvtidy dedupe

Remove duplicate rows, preserving input order.

exact duplicate rows
csvtidy dedupe combined.csv --output deduped.csv
rows are duplicates when one column matches; keep the first seen
csvtidy dedupe combined.csv --subset email --keep first
optionwhat it does
-o, --output PATHWrite to this CSV. Omit for stdout.
--subset COLSComma-separated columns to match on (default: all columns).
--keep first|lastWhich duplicate to keep (default first).

csvtidy clean

Apply cleanup primitives: trim whitespace, collapse internal runs, drop blank rows, rewrite mixed date formats to one format.

csvtidy clean feb.csv --fix-dates signup_date --collapse-spaces --output feb.clean.csv
optionwhat it does
--trim / --no-trimTrim leading/trailing whitespace (default on).
--drop-empty-rowsDrop rows where every cell is blank (default on).
--collapse-spacesCollapse internal whitespace runs to a single space.
--fix-dates COLSColumns to normalize to one date format.
--date-format FMTOutput format for --fix-dates (default %Y-%m-%d).
--dayfirstRead ambiguous dates day-first (03/04 = 3 April).

csvtidy run recipe.yaml

A recipe captures a whole cleanup as a small YAML file — build it once, replay it on any new batch. Steps compose into a single DuckDB query, keeping the larger-than-RAM streaming.

input: exports/*.csv
output: customers.clean.csv
source_column: source_file
steps:
  - clean: { trim: true, fix_dates: [signup_date] }
  - dedupe: { subset: [email], keep: first }
csvtidy run recipe.yaml

Commands also pipe like any Unix tool — omit --output and CSV goes to stdout, progress to stderr:

csvtidy merge ./exports | csvtidy dedupe - --subset email > clean.csv

how it works

csvtidy is a thin, friendly layer over DuckDB. Each command builds one SQL query and lets DuckDB do the heavy lifting: it reads CSVs directly, processes them streaming, and spills to disk when the job is bigger than memory. Merging a folder of multi-gigabyte exports works on an ordinary laptop.
